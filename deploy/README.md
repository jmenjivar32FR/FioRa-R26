# Despliegue

FioRa se distribuirá como una instancia independiente por cliente, en infraestructura local o alojada.

Esta carpeta se completará cuando se definan:

- requisitos mínimos del servidor;
- configuración de PostgreSQL;
- empaquetado de backend y frontend;
- uso de Docker / Docker Compose;
- gestión de secretos;
- migraciones y actualización;
- respaldos y restauración;
- procedimiento de instalación y diagnóstico.

No se incluye todavía un `Dockerfile` ni `compose.yaml` para no fijar servicios, versiones o comandos antes de diseñar el entorno ejecutable.
