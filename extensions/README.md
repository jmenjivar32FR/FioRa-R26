# Adaptaciones y extensiones de cliente

Las adaptaciones particulares deben permanecer encapsuladas y no alterar innecesariamente FioRa Core.

**No coloques aquí código, configuraciones, credenciales, datos ni documentos propiedad de un cliente dentro del repositorio común sin autorización contractual expresa.** La ubicación técnica y distribución de extensiones se decidirá considerando la titularidad que se haya pactado con cada cliente. Cuando corresponda, pueden mantenerse en repositorios privados independientes o paquetes separados.
