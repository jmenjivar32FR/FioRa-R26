# Pruebas del backend

- `unit/`: reglas y unidades aisladas.
- `integration/`: interacción entre módulos y adaptadores reales o controlados.
- `contract/`: cumplimiento de contratos entre componentes.

Los datos deben ser ficticios o anonimizados. Las pruebas de integración con PostgreSQL se definirán cuando exista el entorno de desarrollo.
