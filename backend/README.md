# Backend FioRa

El backend se desarrollará en Python y seguirá la dirección de monolito modular.

La carpeta `src/fiora/` contiene el paquete de aplicación. La estructura separa capacidades comunes, el primer flujo operativo, capacidades auxiliares e infraestructura.

Todavía no se incluye `pyproject.toml`, `requirements.txt` ni un framework API porque falta elegir el framework, el ORM, la herramienta de migraciones, el gestor de dependencias y las versiones compatibles. Cuando se elijan, se documentarán y fijarán.
