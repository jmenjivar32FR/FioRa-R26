# Documentación

El Documento Maestro es la fuente principal de las decisiones de producto y arquitectura.

- `product/`: visión, alcance y decisiones consolidadas.
- `commercial/`: licenciamiento y marco legal preliminar.
- `architecture/`: modelo arquitectónico, límites y decisiones técnicas.
- `development/`: guías para trabajar en el repositorio.
- `references/`: propuestas anteriores y material de consulta histórico.

Cuando una decisión cambie, actualiza el Documento Maestro y registra una decisión arquitectónica (ADR) si afecta estructura, dependencias, persistencia, seguridad, contratos o despliegue.
